# Dados Internacionais (`data/core/international/`)

Este diretório armazena os arquivos declarativos compartilhados de competições internacionais, clubes complementares de IA e seleções nacionais (populados integralmente na **Fase 2 — Mundo Completo**):

- Competições Continentais: UEFA (Champions / Europa / Conference — 36 clubes), CONMEBOL (Libertadores / Sul-Americana / Recopa), AFC Champions League Elite (24 clubes).
- Competições Mundiais: Copa Intercontinental (anual) e Mundial de Clubes de 32 clubes (quadrienal).
- Seleções Nacionais: ~64 seleções, Eliminatórias, Copas Continentais e Copa do Mundo de 48 seleções.
- Clubes complementares de IA (substituídos automaticamente quando o usuário instalar um `.fmpack` jogável daquela confederação).
