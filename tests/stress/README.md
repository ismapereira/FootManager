# Testes de Estresse (`tests/stress/`)

Este diretório receberá o teste automatizado obrigatório de **10 temporadas consecutivas** (Seção 11.3), simulando todas as 15 divisões, copas, competições continentais (Champions 36, Libertadores/Sul-Americana, AFC Elite), Intercontinental, Mundial de 32 clubes e Copa do Mundo de 48 seleções nas Fases 2 e 4.
